# Standard Laptop Task Automation


A ServiceNow System Administrator project that uses Flow Designer to automate laptop catalog task creation. The flow is configured to create a Catalog Task (`sc_task`), associate the Requested Item record, and assign the task to the Hardware group.

## Project Details

* **Platform:** ServiceNow
* **Tool:** Flow Designer
* **Target Table:** Catalog Task (`sc_task`)
* **Assignment Group:** Hardware
* **Flow Name:** Standard laptop task
* **Status:** Active
